# 개념튼튼 ON싹 개발 현황

> 마지막 업데이트: 2026-05-26

---

## 앱 개요

초등학생 대상 자기주도학습 앱. EBS 초등 교재 4개 과목 연계.

| 과목 | 이름 | 대상 | 상태 |
|---|---|---|---|
| 어휘 | 어휘싹 | 1~6학년 | ✅ 실서비스 |
| 개념 | 개념싹 | 3~6학년 | ✅ 실서비스 |
| 독해 | 독해싹 | 2~6학년 | 🟡 UI 완성, 콘텐츠 미완 |
| 영어 | 영어싹 | 3~6학년 | 🟡 UI 완성, 영상 URL 미입력 |

## IndexedDB 키 구조

```
students                     Student[] 전체 목록
activeStudentId              현재 활성 학생 ID

p|{sid}|vocab|{itemId}       낱말 진도 (done, starred, score, lastVisitedAt)
  itemId: g1-001 ~ g4-060   (낱말), review-3 ~ review-60 (다섯고개)

p|{sid}|concept|{videoId}    개념 영상 진도
  videoId: c3-1-science-u1-v1 등

p|{sid}|reading|{topicId}    독해 주제 진도
  topicId: g3-t1 ~ g6-t30

p|{sid}|english|{itemId}     영어 단원 진도
  itemId: 3-01 ~ 6-NN

r|{sid}                      최근 학습 목록 (RecentEntry[], 최대 20개)
b|{sid}                      취득 뱃지 코드 목록 (string[])
```

## 기술 스택

| 레이어 | 기술 |
|---|---|
| 프론트 | React 18, TypeScript, Vite, React Router v6 |
| 스타일 | Tailwind CSS (커스텀 토큰: sprout·sky2·sun·coral·violet) |
| 저장소 | IndexedDB (idb-keyval) — 로컬, 계정 없음 |
| 서버 | Cloudflare Pages Functions (Edge) |
| DB | Cloudflare D1 (SQLite) — `ssac-app` |
| AI 채점 | Gemini gemini-flash-lite-latest |
| 단축 URL | edu-link API (`dgedu.link/api/v1/shorten`) |
| 폰트 | Nunito (Google) + Pretendard (jsdelivr) |
