## 완료된 기능

### 인프라 · 공통
- [x] Vite + React 18 + TypeScript + Tailwind CSS 프로젝트 구성
- [x] Cloudflare Pages 배포 설정 (`wrangler.toml`, `schema.sql`)
- [x] Cloudflare D1 연동 (공유 링크 저장/조회, 이벤트 로깅)
- [x] Cloudflare Pages Functions (`/api/grade`, `/api/share`, `/api/track`)
- [x] Zod 콘텐츠 스키마 (`content/schema.ts`)
- [x] IndexedDB 저장소 (`idb-keyval` 래퍼, `src/lib/storage.ts`)
- [x] 경로 별칭 설정 (`@/` → `src/`, `@content/` → `content/`)

### 학생 관리

- [x] 완료·별표 상태 IndexedDB 저장 및 복원
