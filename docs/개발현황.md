## 완료된 기능

### 인프라 · 공통
- [x] Vite + React 18 + TypeScript + Tailwind CSS 프로젝트 구성
- [x] Cloudflare Pages 배포 설정 (`wrangler.toml`, `schema.sql`)
- [x] Cloudflare D1 연동 — DB명 `ssac-app`, UUID 기입 완료
- [x] Cloudflare Pages Functions (`/api/grade`, `/api/share`, `/api/track`)

- [x] 모바일 하단 네비 (최근 방문 과목 2개 자동 반영)
- [x] 학생 없을 때 하단 네비·뱃지 아이콘 숨김

### 어휘싹 (실콘텐츠)
- [x] 어휘 JSON 1~4학년 각 60단어 (`grade-1.json` ~ `grade-4.json`)
- [x] 학년별 단어 그리드 — 3단어 + 다섯고개를 한 행(4열)으로 구성
- [x] 최근 열람 낱말 강조 표시 (주황색 테두리)
- [x] 완료(✓) · 별표(⭐) 표시
- [x] 낱말 글자 크기 확대 (`text-xs sm:text-sm`)
- [x] 단어 학습 화면 (뜻·예시·확인 모듈)
- [x] 확인 모듈 3종: MCQ · Fill · Write (AI 채점)
- [x] MCQ 오답 시 재도전 1회 제공 (1차 정답 100점, 재도전 정답 50점)
- [x] 다섯고개 복습 — 별도 라우트 (`/vocab/:grade/review/:afterIndex`)
- [x] 다섯고개: 영상 슬롯 + 초성 퀴즈 + 완료 처리
- [x] 별표(즐겨찾기) 토글 — 홈 즐겨찾기 섹션 연동
- [x] 완료·별표 상태 IndexedDB 저장 및 복원
- [x] 진도 원형 그래프 + 바 (SVG) — 다섯고개 제외 순수 낱말 기준
- [x] 어휘싹 학년 제한 없음 — 데이터가 있는 1~4학년 모두 선택 가능
- [x] 모든 어휘 하위 페이지에 '← 홈으로' 버튼

### 홈

## 라우트 구조

```
/                         홈
/vocab                    어휘싹 학년 선택
/vocab/:grade             어휘싹 단어 목록
/vocab/:grade/:wordId     단어 학습
/vocab/:grade/review/:afterIndex  다섯고개 복습
/concept                  개념싹 학기/과목 선택
/concept/:grade/:semester 개념싹 과목 대시보드
/concept/:grade/video/:videoId 개념 비디오 학습 및 OX 퀴즈
/reading                  독해싹 (준비중)
/english                  영어싹 (준비중)
/badges                   뱃지 컬렉션
/share                    공유 수신
/admin/data               데이터 관리 (PIN)
/admin/vocab              어휘 편집 (dev only)
```

## IndexedDB 키 구조

```
students                  Student[] 전체 목록
activeStudentId           현재 활성 학생 ID
p|{sid}|vocab|{itemId}    낱말 진도 (done, starred, score, lastVisitedAt)
  itemId: g1-001 ~ g4-060 (낱말), review-3 ~ review-60 (다섯고개)
r|{sid}                   최근 학습 목록 (RecentEntry[], 최대 20개)
b|{sid}                   취득 뱃지 코드 목록 (string[])
```
