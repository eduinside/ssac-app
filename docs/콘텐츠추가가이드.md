# 콘텐츠 추가 가이드

관리자가 새 학습 자료를 앱에 추가하는 방법을 설명합니다.

---

## 어휘싹 콘텐츠 추가

### 방법 A — 관리자 웹 폼 (권장, 로컬 dev 전용)

1. `npm run dev` 실행
2. 브라우저에서 `http://localhost:5299/admin/vocab` 접속
3. 학년 선택 → 단어 행 추가/편집
4. **JSON 다운로드** 클릭
5. 받은 파일을 `content/vocab/grade-N.json`에 덮어쓰기
6. `git commit` 후 push → 자동 배포

> `/admin/vocab`은 `npm run build` 프로덕션 빌드에는 포함되지 않습니다.

---

### 방법 B — JSON 직접 편집

`content/vocab/grade-N.json` 파일을 직접 수정합니다.

#### 파일 구조

```json
{
  "grade": 1,
  "words": [
    {
      "id": "g1-001",
      "word": "낱말",
      "meaning": "뜻을 가진 말의 가장 작은 단위.",
      "examples": [
        "오늘 새 낱말을 세 개 배웠다.",
        "낱말을 카드에 적어 두자."
      ],
      "check": {
        "type": "mcq",
        "prompt": "'낱말'의 뜻으로 알맞은 것은?",
        "choices": ["문장 전체", "뜻을 가진 말의 가장 작은 단위", "노래의 한 구절", "그림의 한 부분"],
        "answer": 1
      }
    }
  ],
  "reviews": [
    {
      "afterIndex": 3,
      "title": "1~3번 낱말 복습",
      "videoUrl": "https://example.com/review1.mp4",
      "chosungQuiz": [
        { "answer": "낱말", "hint": "뜻을 가진 말의 단위" },
        { "answer": "친구", "hint": "가깝게 지내는 사람" },
        { "answer": "선생님", "hint": "가르쳐 주시는 분" }
      ]
    }
  ]
}
```

#### 필드 설명

**words 항목**

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | string | `g{학년}-{3자리 번호}` 형식. 예: `g1-001` |
| `word` | string | 낱말 |
| `meaning` | string | 뜻풀이 |
| `examples` | string[] | 예문 (0개 이상) |
| `check` | object | 확인 모듈 (아래 참조) |

**check 모듈 종류**

```jsonc
// MCQ (객관식, 4지선다)
{ "type": "mcq", "prompt": "질문", "choices": ["①", "②", "③", "④"], "answer": 1 }
// answer는 정답 choices 인덱스 (0부터 시작)

// Fill (빈칸 채우기)
{ "type": "fill", "prompt": "빈칸을 채워 보세요: ___ 와 놀았다.", "answer": "친구", "hint": "가깝게 지내는 사람" }

// Write (서술형 — AI 채점)
{ "type": "write", "prompt": "낱말을 사용해서 문장을 써 보세요.", "rubric": "낱말의 뜻을 살려 문장을 완성하면 정답." }
```

**reviews 항목**

| 필드 | 타입 | 설명 |
|---|---|---|
| `afterIndex` | number | 몇 번째 단어 완료 후 등장할지 (1부터 시작) |
| `title` | string | 다섯고개 제목 |
| `videoUrl` | string? | 복습 영상 URL (없으면 생략) |
| `chosungQuiz` | array | 초성 퀴즈 목록 |

`chosungQuiz` 항목:
```jsonc
{ "answer": "낱말", "hint": "뜻을 가진 말의 단위" }
```

## 관리자 데이터 페이지 (`/admin/data`)

학생 학습 데이터를 조회·관리합니다. **모든 빌드에 포함**, PIN으로 보호.

- PIN: `.env` 파일의 `VITE_ADMIN_PIN` (없으면 기본값 `0000`)
- 학생별 뱃지·최근 학습·어휘 진도 확인
- JSON 내보내기 (전체 또는 학생별)
- 학생 삭제 (연관 데이터 일괄 삭제)

> `.env` 예시:
> ```
> VITE_ADMIN_PIN=1234
> ```

---

## 콘텐츠 ID 규칙

- 어휘: `g{학년}-{3자리}` — 예: `g1-001`, `g3-060`
- 학년은 변경 불가 (progress 키에 포함됨). ID를 바꾸면 기존 진도가 초기화됩니다.
