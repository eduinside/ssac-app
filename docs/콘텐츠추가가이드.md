# 콘텐츠 추가 가이드

관리자가 새 학습 자료를 앱에 추가하는 방법을 설명합니다.  
각 과목별로 **원본 PDF에서 데이터를 추출하는 작업 흐름**을 포함합니다.

---

## 공통 원칙

- 콘텐츠 파일 위치: `content/{과목}/`
- 스키마 정의: `content/schema.ts` (Zod)
- **ID는 절대 변경하지 말 것** — IndexedDB 진도 데이터의 키로 사용됨
- 편집 후 `git commit` → push → Cloudflare Pages 자동 배포

## 어휘싹 (Vocab)

### PDF 구성

- 교재: EBS 초등 어휘 (학년별)
- 구성: 낱말 + 뜻풀이 + 예문 2개 + 확인 문제 1개 (객관식/빈칸/서술형)

### PDF → JSON 추출 절차

1. PDF를 열고 각 단원 낱말 목록 확인
2. 낱말 순서대로 번호를 매겨 `id` 부여: `g{학년}-{3자리}` (예: `g1-001`)
3. 뜻풀이를 그대로 옮김 (사전체 문어체 유지)
4. 예문 2개 입력 (교재 수록 예문 우선, 없으면 창작)
5. 확인 문제 유형 선택:
   - 4지선다 → `mcq` (가장 일반적)
   - 빈칸 채우기 → `fill`
   - 글쓰기 → `write` (AI 채점)
6. 완성된 JSON을 `content/vocab/grade-N.json`에 저장

### 파일 구조

```json
{
  "grade": 1,
  "words": [
    {
      "id": "g1-001",
      "word": "낱말",
      "meaning": "뜻을 가진 말의 가장 작은 단위.",
      "examples": [
        "오늘 새 낱말을 세 개 배웠다.",
        "낱말을 카드에 적어 두자."
      ],
      "check": {
        "type": "mcq",
        "prompt": "'낱말'의 뜻으로 알맞은 것은?",
        "choices": ["문장 전체", "뜻을 가진 말의 가장 작은 단위", "노래의 한 구절", "그림의 한 부분"],
        "answer": 1
      }
    }
  ],
  "reviews": [
    {
      "afterIndex": 3,
      "title": "1~3번 낱말 복습",
      "videoUrl": "https://example.com/review1.mp4",
      "chosungQuiz": [
        { "answer": "낱말", "hint": "뜻을 가진 말의 단위" }
      ]
    }
  ]
}
```

### 필드 설명

**words 항목**

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | string | `g{학년}-{3자리}` (예: `g1-001`) |
| `word` | string | 낱말 |
| `meaning` | string | 뜻풀이 |
| `examples` | string[] | 예문 (0개 이상) |
| `check` | object | 확인 문제 |

**check 유형**

```jsonc
// MCQ (4지선다)
{ "type": "mcq", "prompt": "질문", "choices": ["①", "②", "③", "④"], "answer": 1 }
// answer는 정답 choices의 인덱스 (0부터 시작)

// Fill (빈칸 채우기)
{ "type": "fill", "prompt": "빈칸을 채워 보세요: ___ 와 놀았다.", "answer": "친구", "hint": "가깝게 지내는 사람" }

// Write (서술형 — AI 채점)
{ "type": "write", "prompt": "낱말을 사용해서 문장을 써 보세요.", "rubric": "낱말의 뜻을 살려 문장을 완성하면 정답." }
```

**reviews 항목**

| 필드 | 타입 | 설명 |
|---|---|---|
| `afterIndex` | number | N번째 단어 완료 후 등장 (1부터 시작) |
| `title` | string | 복습 제목 |
| `videoUrl` | string? | 복습 영상 URL (없으면 생략) |
| `chosungQuiz` | array | 초성 퀴즈 |

### 관리자 웹 폼 (로컬 dev 전용)

1. `npm run dev`
2. `http://localhost:5299/admin/vocab` 접속
3. 학년 선택 → 단어 행 추가/편집
4. **JSON 다운로드** → `content/vocab/grade-N.json`에 덮어쓰기

> `/admin/vocab`은 프로덕션 빌드에 포함되지 않음

### 현황

|---|---|---|
| 1학년 | 60개 | ✅ 완료 |
| 2학년 | 60개 | ✅ 완료 |
| 3학년 | 42개 | ✅ 완료 |
| 4학년 | 42개 | ✅ 완료 |
| 5학년 | — | ⬜ 미작성 |
| 6학년 | — | ⬜ 미작성 |

## 개념싹 (Concept)

### PDF 구성

- 교재: EBS 초등 개념싹 (학년·학기·과목별)
- 과목: 사회 / 수학 / 과학
- 구성: 단원(unit) → 영상(video) → 개념어(term) + OX 퀴즈
- 대상: 3~6학년 1·2학기

### PDF → JSON 추출 절차

1. 해당 학년·학기·과목 PDF 열기
2. 단원 목록 파악 → `units[]` 작성
3. 각 단원의 영상(강의) 목록 파악 → `videos[]` 작성
4. 각 영상에서:
   - 핵심 개념어와 뜻 추출 → `concepts[]`
   - OX 퀴즈 2개 작성 → `quiz[]` (참·거짓 각 1개 권장)
5. 파일명 규칙: `grade-{학년}-{학기}-{과목}.json`
   - 과목 코드: `social` / `math` / `science`
6. `content/concept/` 에 저장

### 파일 구조

```json
{
  "grade": 3,
  "semester": 1,
  "subject": "science",
  "units": [
    {
      "id": "u1",
      "title": "1. 힘과 우리 생활",
      "videos": [
        {
          "id": "c3-1-science-u1-v1",
          "title": "힘이란 무엇일까요?",
          "youtubeUrl": "",
          "concepts": [
            {
              "term": "힘",
              "meaning": "물체의 모양이나 움직임을 변화시킬 수 있는 것",
              "example": "두꺼운 반죽에 힘을 주어 얇게 펴거나, 힘을 주어 무거운 수레를 움직이는 것"
            }
          ],
          "quiz": [
            {
              "type": "ox",
              "prompt": "물체에 힘을 가하면 물체의 모양이나 움직임이 변할 수 있습니다.",
              "answer": true
            },
            {
              "type": "ox",
              "prompt": "힘은 물체를 밀거나 당길 때만 작용하고, 물체의 모양은 절대 바꾸지 못합니다.",
              "answer": false
            }
          ]
        }
      ]
    }
  ]
}
```

### ID 규칙

- 영상 ID: `c{학년}-{학기}-{과목코드}-u{단원번호}-v{영상번호}`
  - 예: `c3-1-science-u1-v1`, `c4-2-math-u3-v2`

| 학년 | 학기 | 사회 | 수학 | 과학 |
|---|---|---|---|---|
| 3학년 | 1학기 | ✅ | ✅ | ✅ |
| 3학년 | 2학기 | ✅ | ✅ | ✅ |
| 4학년 | 1학기 | ✅ | ✅ | ✅ |

## 독해싹 (Reading)

### PDF 구성

- 교재: EBS 초등 독해싹 (학년별)
- 구성: 주제(topic) → 지문(read) → 활동(activities, MCQ/Fill) → 심화(apply, 서술형)
- 대상: 2~6학년, 학년당 30주제

### PDF → JSON 추출 절차

1. 해당 학년 PDF 열기
2. 주제 목록 확인 (30주제) → `topics[]` 제목 작성
3. 각 주제에서:
   - 지문 텍스트 추출 → `read` 필드 (줄바꿈은 `\n` 사용)
   - 독해 확인 문제(1~3개) → `activities[]` (MCQ 또는 Fill)
   - 심화 쓰기 활동 → `apply[]` (서술형, AI 채점 사용 가능)
4. 파일명 규칙: `grade-{학년}.json`
5. `content/reading/` 에 저장

### 파일 구조

```json
{
  "grade": 3,
  "topics": [
    {
      "id": "g3-t1",
      "title": "웃음 참는 나무",
      "read": "옛날 어느 마을에...\n\n나무가 흔들렸습니다.",
      "activities": [
        {
          "type": "mcq",
          "prompt": "이 글의 주제로 알맞은 것은?",
          "choices": ["나무의 성장", "웃음의 힘", "숲의 생태", "마을의 역사"],
          "answer": 1
        },
        {
          "type": "fill",
          "prompt": "나무가 웃음을 참는 이유는 _____ 때문입니다.",
          "answer": "겸손",
          "hint": "자신을 낮추는 마음"
        }
      ],
      "apply": [
        {
          "id": "g3-t1-a1",
          "label": "생각 넓히기",
          "prompt": "웃음을 참아야 했던 경험을 떠올려 써 보세요.",
          "example": "발표 시간에 친구가 실수해서 웃음이 나왔지만 참았습니다."
        }
      ]
    }
  ]
}
```

### ID 규칙

- 주제 ID: `g{학년}-t{번호}` (예: `g3-t1` ~ `g3-t30`)
- 심화 ID: `{주제ID}-a{번호}` (예: `g3-t1-a1`)

### 현황

| 학년 | 주제 수 | 지문 | 상태 |
|---|---|---|---|
| 2학년 | 30 | ⬜ 제목만 있음 | 🔴 미완 |
| 3학년 | 30 | ⬜ 제목만 있음 | 🔴 미완 |
| 4학년 | 30 | ⬜ 제목만 있음 | 🔴 미완 |
| 5학년 | — | — | ⬜ 미작성 |
| 6학년 | — | — | ⬜ 미작성 |

> 현재 주제 제목만 입력된 상태. 지문(`read`)과 활동(`activities`, `apply`)은 PDF에서 추출 필요.

## 영어싹 (English)

### PDF/영상 구성

- 교재: EBS 초등 영어싹 (학년별)
- 구성: 단원(item) → 영상 링크(videoUrl) → 확인 퀴즈(quiz)
- 대상: 3~6학년

### PDF/영상 목록 → JSON 추출 절차

1. 해당 학년 교재 목차에서 단원 제목 목록 파악
2. EBS 영상 플랫폼에서 각 단원의 영상 URL 수집
3. 각 단원에서 확인 퀴즈 1개 작성 (MCQ 권장)
   - 영상 내용 기반으로 출제
   - 등장인물·상황·핵심 표현 관련 질문
4. 파일명 규칙: `grade-{학년}.json`
5. `content/english/` 에 저장

### 파일 구조

```json
{
  "grade": 3,
  "items": [
    {
      "id": "3-01",
      "title": "Happy Zookeeper",
      "videoUrl": "https://example.com/video.mp4",
      "quiz": {
        "type": "mcq",
        "prompt": "다음 등장 인물의 직업으로 알맞은 것을 고르시오.",
        "choices": ["doctor", "teacher", "zookeeper", "pilot"],
        "answer": 2
      }
    }
  ]
}
```

### ID 규칙

- 아이템 ID: `{학년}-{2자리 번호}` (예: `3-01`, `4-12`)

### 현황

| 학년 | 단원 수 | 영상 URL | 퀴즈 | 상태 |
|---|---|---|---|---|
| 3학년 | 입력됨 | ⬜ 비어 있음 | ✅ 있음 | 🟡 영상만 필요 |
| 4학년 | 입력됨 | ⬜ 비어 있음 | ✅ 있음 | 🟡 영상만 필요 |
| 5학년 | 입력됨 | ⬜ 비어 있음 | ✅ 있음 | 🟡 영상만 필요 |
| 6학년 | 입력됨 | ⬜ 비어 있음 | ✅ 있음 | 🟡 영상만 필요 |

> 단원 제목과 퀴즈는 입력된 상태. `videoUrl` 필드에 실제 영상 링크만 채우면 즉시 사용 가능.

## 관리자 데이터 페이지 (`/admin/data`)

학생 학습 데이터를 조회·관리합니다. **모든 빌드에 포함**, PIN으로 보호.

- PIN: `.env` 파일의 `VITE_ADMIN_PIN` (없으면 기본값 `0000`)
- 학생별 뱃지·최근 학습·어휘 진도 확인
- JSON 내보내기 (전체 또는 학생별)
- 학생 삭제 (연관 데이터 일괄 삭제)

```
VITE_ADMIN_PIN=1234
```
